BTCZ Tools

A free desktop toolkit for BitcoinZ miners. Everything a BTCZ miner checks daily, in one clean app — now with a standalone Windows .exe: just download and double-click. No Python, no setup.

  • ⚙ 8 modules
  • 🌐 EN / FR / ES / DE
  • 🔑 Free & open source (MIT)
  • 🖥 Windows .exe
Download the latest release View source on GitHub

Built and maintained by community member RGBTCZ. Not an official BitcoinZ release — always download it from the GitHub repository linked above.

What’s inside

Eight modules built on a shared data layer — network data fetched once is reused everywhere.

📊

Dashboard

Network, your mining (today / 7d / 30d), profit and price at a glance.

⛏️

Mining Tracker

Rewards per day or date range, CSV export, and live pool-side stats.

💰

Profitability

Revenue, cost, profit, break-even and ROI, with GPU presets — pick your card and quantity.

🌊

Pool Explorer

On-chain pool distribution plus live stats from zpool, SW Groupe, Dark Fiber Mines and HimPool.

🌐

Network Explorer

Network stats and the latest blocks, each with the miner that found it.

📈

History

Monthly history, projections and alerts on what changed.

🚀

Mining Assistant

Analyzes your setup and gives honest, actionable advice.

🌎

Four languages

English, French, Spanish and German — switch on the fly from the sidebar.

A look inside

Get started in three steps

  1. 1

    Download

    Grab BTCZ-Tools.exe from the latest GitHub release.

  2. 2

    Double-click

    No Python and no install needed on Windows. Prefer running from source? The repository has the instructions.

  3. 3

    Add your address

    Paste your t1 mining address and the dashboard fills in with your own numbers.

Free, open source, community-built

BTCZ Tools is released under the MIT license. Huge thanks to the pool operators who shared their APIs — feedback and pull requests are welcome.
